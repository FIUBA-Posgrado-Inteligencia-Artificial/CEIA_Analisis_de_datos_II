- **`notebooks/`** → Contiene las notebooks con los ejemplos y ejercicios de cada clase.
- **`datasets/`** → Conjunto de datos utilizados en los ejemplos y prácticas.
- **`recursos/`** → Ejericios, reportes y otros materiales útiles.
